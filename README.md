# 同频猜词

一个房间内所有人写同一个词。没有话题，没有提示，只能靠默契。

昵称留空会从热梗昵称池随机分配，同房间自动分配的昵称不重名，断线重连保留昵称；自定义昵称照常使用。

## 玩法

1. 房主创建房间，设置人数上限（2-8）和每轮限时
2. 把邀请链接或 4 位房间码发给其他人
3. 每轮所有人同时提交一个词，提交后不可修改，也看不到别人写了什么
4. 全部提交完立刻结算，服务器判断是否完全一致

两条出路：

- **完全一致**：服务器直接判定成功，本局当场结束，没有投票环节
- **不一致**：自动进入下一轮，新一轮的输入页会显示上一轮的完整结果，任何人可以在那里点「这轮算同频？」投出一票。所有人认定，本局结束

第二条出路是给「土豆 / 马铃薯」这种字面不同但意思一样的情况准备的。服务器只认字面，认不认定由玩家决定，所以一局可能一轮就结束，也可能拖很久。

**已经出现过的词不能再用**，同一轮内允许重复。

## 结果展示

结算页显示本局总轮数与成功轮结果，更早的收在「回看调频现场（N 轮）」里。游戏中可以上下滚动查看历史轮次。两人局的历史记录隐藏名称，成功轮结果保留名称。

结束文案分两套：服务器判定一致的是「脑回路，接上了。」，玩家投票认定的是「系统没懂，你们懂了。」。

「再来一局」需要至少两名在线玩家全员准备，点击可准备或取消，按钮下方显示准备人数与各自状态。临时断线会取消该玩家的准备，重连后可重新准备。

房主点击「返回主页」会先确认，确认后解散房间，所有人返回主页。其他玩家直接退出，剩余玩家回到原房间等待页，准备状态和上一局结果清空；临时断线仍保留重连位置。

## 本地战绩

首页标题右侧的「历」字按钮可打开本地战绩，列表显示完成时间、总轮数、参与者名称和最终答案，答案使用对应颜色的边框并以 × 连接。点击可回看每一轮；名字仅在最终结果显示，逐轮记录隐藏名字，回看页也隐藏顶部的本地存储说明。

只有完全一致或全员认定的成功对局会保存；中途有玩家断线（包括刷新重连）或主动退出的对局不留存。完成后才断线或返回主页不影响已保存的记录。同一局的准备、重连及刷新不会重复保存。

记录仅保存在当前浏览器、当前网站地址的本地存储中，不上传服务器。清除浏览器数据、使用其他浏览器或更换网站地址无法读取原有记录；无痕模式的记录可能在关闭窗口后清除。存储不可用或已满时会提示保存失败，不自动清理旧记录。

## 运行

```bash
npm install
npm start        # http://localhost:3000
npm test         # 端到端自检
```

局域网测试用启动时打印的地址，不要用 localhost，否则「复制链接」拷出来的地址对方打不开。

## 设计取舍

- 只有 `ws` 一个依赖，前端零框架零构建，一个页面一个服务端文件
- 房间状态在进程内存里，重启即丢。房间里没有值得落库的东西
- 词比较前做 NFKC + 去空白 + 转小写，所以 `Apple` 和 `apple ` 视为同一个词
- 本轮已提交的词绝不下发，只有结算完的轮次才进入下发给客户端的历史
- 超时和掉线的人视为弃权，不阻塞其余人；人数不足 2 人时回合不推进
- 折叠用原生 `<details>`，配合实际高度动画兼容手机浏览器
- 测试用随机端口并对退出做清理，避免断言失败时留下孤儿进程占着端口跑旧代码
